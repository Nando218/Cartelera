# A24 Movie Board

An interactive movie board showcasing films from the A24 studio. This project uses **JavaScript** and **Bootstrap** to deliver an intuitive and dynamic experience. Users can search for their favorite movies, explore the available list, and watch trailers by clicking on the movie image.

---

## 🎬 Main Features

- **Search Filter:** Quickly find any movie using the search box.
- **Trailer Viewing:** Click on a movie image to open its corresponding trailer.
- **Attractive Design:** Interface styled with **Bootstrap** for a modern and responsive look.

---

## 🛠️ Technologies Used

- **JavaScript:** Logic for filtering and interaction control.
- **Bootstrap:** Structure and responsive styling.
